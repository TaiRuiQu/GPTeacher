# GPT Teacher

黑白与蓝色主题的桌面 AI 课堂。一个大白板负责讲解，右侧是可收起的学习树、提问、练习、笔记和讲稿。课程使用真实树状结构，教学任务由 Codex 或 Claude Code agent 执行。

## 启动

需要 Node.js 22.18+，以及已安装、登录的 Codex 或 Claude Code。

```powershell
npm install
npm run dev
```

打开 `http://127.0.0.1:5173`，网页和 API 由同一服务提供。正式运行：

```powershell
npm run build
npm start
```

默认后端是 Claude Code。首次使用前在运行服务的系统账户下执行 `claude auth login` 或 `codex login`，在学习设置中选择后端。程序检测只确认安装情况，实际任务还需有效登录与账户额度。平台不要求学生填写 API Key。

CLI 不在 PATH 中时，在 `.env.local` 设置 `CODEX_CLI_PATH` 或 `CLAUDE_CLI_PATH`。可配置项见 `.env.example`。

## 先研究，再选择，最后生成

1. 输入章节名称，例如“人教版七年级上册 · 一元一次方程”，选择学科与候选课时数量。
2. Agent 实际执行网页搜索或读取，研究该章节的知识点、解题技巧和相关课程，整理带来源的课程树。
3. 在树中查看章节和课时。点击候选课时，可以预览知识点、学习目标、技巧和来源。
4. 勾选需要的课时，再点击 **生成所选讲解**。未勾选的课时保留为待生成状态，不产生讲义。
5. 生成经过检查后，进入白板学习。练习、答疑和笔记在右侧完成。

```text
数学
└─ 一元一次方程
   ├─ 认识等式与方程
   │  ├─ 未知数与数量关系
   │  └─ 等式的性质
   └─ 求解与实际应用
      ├─ 移项与合并
      └─ 列方程解决问题
```

章节旁的加号可在当前位置研究子章节。练习后的巩固建议也添加为原课程树中的分支，再按需选择生成；不会变成一组没有关联的平行课程。

研究阶段必须有真实工具轨迹，引用地址须匹配实际搜索结果或成功读取的页面。工具不可用、检索无结果或引用无法核对时会报告失败，不用模型记忆冒充联网研究。

## 语音课堂

- **TTS**：点击播放后朗读当前讲稿，语音边界同步当前讲解位置。可关闭朗读，改为只看白板。
- **ASR 与 VAD**：开启语音对话并允许麦克风。系统检测说话、识别文字，在停顿后自动提交问题。
- **插话**：播放期间说出问题，课堂暂停，并固定打断时的课程树路径、课时、片段、播放位置、板书和讲稿位置。识别完成后的提交继续使用这份快照。
- **回答与续播**：新回答自动朗读，之后可以从原来的位置继续学习。文字提问也会携带课堂上下文。

当前集成使用桌面浏览器的 SpeechSynthesis、SpeechRecognition 与 Web Audio。语音识别依赖浏览器支持、麦克风权限和识别服务连接；朗读音色来自浏览器或系统。设备与网络错误会显示在课堂中，识别失败不会伪装成成功。

浏览器有字词边界时记录字词位置；没有时明确标注为估计或片段位置，模型不会把估计当作精确听完的位置。麦克风启用时使用回声消除与噪声抑制，并过滤与当前朗读一致的回声。

## 讲义格式

讲义只需要普通 Markdown：

```markdown
# 理解等式

用数量关系寻找未知数。

## 观察一个例子

一支笔和一本 3 元的本子一共 7 元，可以写成 x + 3 = 7。

## 等号两边保持平衡

两边同时减去 3，得到 x = 4。

## 检验结果

把 4 代回原式，4 + 3 = 7。
```

二级标题自动成为可播放片段。SVG 可作为可选板书；没有 SVG 时，白板直接呈现当前片段正文。练习、答案、知识点和来源作为独立结构保存。

## 数据和开发原则

`.data/platform.json` 保存课程树、档案、进度、对话、练习、笔记和任务检查点。任务刷新后继续，失败和中断可重试。所有确定性写入由服务器完成，agent 不直接操作数据库。

遵照 [AGENTS.md](AGENTS.md)，开发中直接重新生成数据库，不提供版本迁移或数据兼容处理。本项目按桌面端开发，不把无障碍与移动端适配作为要求。

示例课程用于直接体验，明确标记为示例。它们不是联网研究结果，也不是完整官方 K12 教材库。“已学完”记录完成情况，掌握情况以练习证据为依据。
